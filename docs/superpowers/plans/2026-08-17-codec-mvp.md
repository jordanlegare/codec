# CODEC Executable MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a dependency-light C++20 CODEC product that creates, verifies, repairs, queries, and extracts CODA archives and issues/detects cryptographically bound W1/W2 feed watermarks.

**Architecture:** A static/shared C++ core separates archive, audio, watermark, capture, engine, and C ABI responsibilities. A single CLI composes those APIs, while optional model backends advertise availability without changing preservation semantics.

**Tech Stack:** C++20, CMake 3.20+, OpenSSL 3, libcurl, CTest, POSIX file I/O, GitHub Actions.

## Global Constraints

- Preserve accepted S0 bytes exactly and label all generated audio as derived.
- Verify SHA-256 content, a previous-record chain, and complete commit trailers.
- Never report authoritative `verified_feed` from the stateless reference detector; three hops plus valid Ed25519 COSE W0 may report only `signature_bound_candidate` until replay-safe fusion ships.
- Keep W1 below 20 kHz and enable W2 only at sample rates of at least 96 kHz with a 2 kHz Nyquist guard.
- Never expose OpenSSL, curl, FFmpeg, ONNX, CUDA, or vendor types in public headers.
- Exceptions never cross the versioned C ABI.
- Neural and GPU capability reports must reflect the runtime truth.
